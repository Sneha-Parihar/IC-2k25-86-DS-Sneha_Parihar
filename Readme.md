Lab 01: Queue

Programs:

Priority Queue Implementation
Queue Implementation

Problem Statement: Implement queue data structures and understand their operations, including insertion and deletion.

Approach:

Implement queue operations.
Understand FIFO (First In, First Out).
Implement priority-based element processing.

Complexity:

Operation	Time Complexity
Enqueue	O(1)
Dequeue	O(1)
Peek	O(1)

Priority queue complexity depends on its implementation.

Learning Outcomes:

Understand FIFO principles.
Learn queue operations.
Understand priority-based processing.
Lab 02: Searching

Programs:

Linear Search
Recursive Linear Search

Problem Statement: Search for a given element in an array using iterative and recursive approaches.

Approach:

Linear Search checks each element sequentially.
Recursive Linear Search checks elements using recursive function calls.

Complexity:

Algorithm	Time Complexity	Space Complexity
Linear Search	O(n)	O(1)
Recursive Linear Search	O(n)	O(n)

Learning Outcomes:

Understand searching techniques.
Differentiate iterative and recursive approaches.
Analyze algorithm complexity.
Lab 03: Sorting

Programs:

Bubble Sort
Merge Sort
Quick Sort
Selection Sort

Problem Statement: Arrange array elements in ascending or descending order using different sorting algorithms.

Approach:

Bubble Sort: Repeatedly compares adjacent elements.
Merge Sort: Divides the array and merges sorted parts.
Quick Sort: Uses a pivot to partition the array.
Selection Sort: Selects the minimum element and places it in the correct position.

Complexity Analysis:

Algorithm	Best Case	Average Case	Worst Case
Bubble Sort	O(n)	O(n²)	O(n²)
Merge Sort	O(n log n)	O(n log n)	O(n log n)
Quick Sort	O(n log n)	O(n log n)	O(n²)
Selection Sort	O(n²)	O(n²)	O(n²)

Learning Outcomes:

Understand different sorting techniques.
Compare sorting algorithm performance.
Analyze time and space complexity.
Lab 04: Stack

Programs:

Stack Implementation

Problem Statement: Implement a stack and perform basic operations such as Push, Pop, and Peek.

Approach:

Use the LIFO (Last In, First Out) principle.
Insert elements using Push.
Remove elements using Pop.
Display the top element using Peek.
Handle stack overflow and underflow conditions where applicable.

Complexity Analysis:

Operation	Time Complexity
Push	O(1)
Pop	O(1)
Peek	O(1)

Learning Outcomes:

Understand stack data structures.
Learn LIFO operations.
Handle stack overflow and underflow.
